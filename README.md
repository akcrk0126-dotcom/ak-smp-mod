# AK SMP 모드 (Fabric, Minecraft Java 26.3)

아르고나이트 광석·장비, 세트 갑옷 4종, 갓 엠페러 갑옷, 가챠 티켓·상자가 **진짜 블럭·아이템**으로 들어 있고(크리에이티브 "AK SMP" 탭),
허브·격투장·경제·가챠·땅 보호 같은 서버 시스템도 이 모드 하나에 다 들어 있어. 서버와 모든 플레이어가 같은 모드를 깔아야 해.

## 다운로드
[Releases → latest](../../releases/latest) 에서
- `ak-smp-버전.jar` (이 모드)
- `fabric-api.jar` (필수 라이브러리)

## 플레이어 설치
1. https://fabricmc.net/use/installer/ 에서 Fabric 설치 프로그램 실행 → 버전 26.3 → 설치
2. `.minecraft/mods` 폴더에 위 jar 두 개 넣기
3. 런처에서 `fabric-loader-26.3` 프로필로 실행

## 서버 (마인헛 등)
서버 종류를 Fabric 26.3 으로 바꾸고 `mods` 폴더에 jar 두 개를 넣은 뒤 재시작.
기존 데이터팩(AK-SMP-*.zip)은 월드의 `datapacks` 폴더에서 **빼야** 해(모드 안에 새 버전이 들어 있음).
예전 버전에서 받은 아이템은 접속하면 자동으로 진짜 모드 아이템으로 바뀌고(인챈트 유지), 예전 아르고나이트 광석도 그대로 원석이 나와.

이 저장소는 생성기가 자동으로 만든 파일이야. 푸시할 때마다 GitHub Actions가 빌드 → 실제 26.3 Fabric 서버로 켜보기 → 릴리스까지 해.
